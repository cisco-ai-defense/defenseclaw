DefenseClaw third-party license text

This file currently reproduces the exact upstream license text for the
production Go module added for DefenseClaw's POSIX shell action parser:
mvdan.cc/sh/v3 v3.13.1. It is a scoped attribution artifact for that dependency
addition, not an exhaustive inventory of every dependency in every DefenseClaw
artifact.

GoReleaser archive Syft SBOM sidecars inventory the gateway archives. The
Windows Setup merged SPDX 2.3 SBOM inventories the exact Go module closure
reported by `go version -m` for its payload binaries as well as the rest of the
installer payload. The declared dependency manifests remain go.mod/go.sum
(Go) and pyproject.toml/uv.lock (Python). The shipped OpenClaw TypeScript plugin
is built from extensions/defenseclaw/package.json and
extensions/defenseclaw/openclaw.plugin.json; the runtime archive carries them
as root package.json and openclaw.plugin.json files.
extensions/defenseclaw/package-lock.json is its locked build input but is not
placed in that runtime archive. The docs-site/package.json and
docs-site/package-lock.json files belong to the separately deployed
documentation site, not a DefenseClaw runtime artifact.
