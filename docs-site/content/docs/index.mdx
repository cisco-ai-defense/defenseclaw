DefenseClaw checks what your AI coding agent installs and does. It scans skills and MCP servers, judges each prompt and tool call, blocks the unsafe ones when you ask it to, and records every decision.

<DefenseClawDemo scenario="modes-same-event" variant="hitl" />

The demo sends one synthetic Claude Code `PreToolUse` event with a HIGH finding through three modes:

- **Observe** lets the call run and records it.
- **Action** blocks it. The demo sets the block level to HIGH; the shipped default blocks CRITICAL and alerts on MEDIUM and above.
- **Action with human approval (HITL)** pauses the call and asks you inside Claude Code.
