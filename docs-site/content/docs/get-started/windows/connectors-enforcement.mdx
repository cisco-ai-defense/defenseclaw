title: Windows connector guidance moved
description: Native Windows connector support, setup, and enforcement guidance now lives on each connector page.

Native Windows connector guidance now lives beside macOS/Linux guidance on
each [connector page](/docs/connectors#platform-support). This route remains as
a compatibility pointer for existing bookmarks; it is no longer a separate
source of connector support or enforcement claims.

Use the connector's own page for setup commands, files, event semantics,
telemetry, HITL behavior, and Windows-only quirks. Use the
[Windows security model](/docs/get-started/windows/telemetry-security) for
platform-wide loopback, credential, DACL, audit, and release-trust boundaries.
