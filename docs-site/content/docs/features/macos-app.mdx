DefenseClaw for macOS is a menu-bar app for Apple-silicon Macs running macOS 14 or newer. It shows gateway health, alerts, inventory and sandboxes, and installs and updates the DefenseClaw runtime. It works only with the DefenseClaw installation on this Mac: the gateway API on `127.0.0.1` and the data under `~/.defenseclaw`. Actions that change something run the `defenseclaw` CLI, and their output appears in **Activity**.

## Install

1. Download `DefenseClawMac-<version>-macos-arm64.dmg` from the [release](/docs/get-started/install) assets.
2. Open the DMG, drag **DefenseClawMac** to **Applications**, and launch it.
3. If DefenseClaw is not installed yet, the **Set Up DefenseClaw** window offers **Install DefenseClaw Runtime**. It downloads the matching `install.sh`, checks it against the release's `checksums.txt`, and installs the CLI and gateway into `~/.defenseclaw` and `~/.local/bin`. Progress shows in **Activity**. An existing `install.sh` installation is used as it is.
4. Pick the agents to guard. Detected agents are pre-selected. Choose observe or action mode.

A release is notarized only when its Apple signing secrets were set at release time. Otherwise the app is ad-hoc signed, and macOS asks you to confirm the first launch. **Update** in the app installs the latest release and keeps your configuration, tokens and audit database. Running `install.sh` again also updates the app (see [Upgrade](/docs/get-started/upgrade)).

## Panels

| Group | Panels |
| --- | --- |
| Monitor | **Overview**, **Alerts**, **Logs**, **Audit**, **Activity** |
| Govern | **Skills**, **MCPs**, **Plugins**, **Tools**, **Policies**, **Sandboxes** |
| Discover | **Inventory**, **AI Discovery**, **Runtime**, **Registries** |
| Configure | **Setup** (setup forms, Sandbox wizard, config editor) |

Most panels match the [TUI](/docs/features/tui). **Settings** has General, Monitoring, Notifications and Connection tabs. The menu-bar popover shows the gateway state, each connector's mode with its call and block counts, and recent events, with **Open DefenseClaw**, **Ack All**, **Pause** and **Quit**. Closing the main window keeps DefenseClaw running in the menu bar.

## Sandboxes

On a Mac, sandboxes are OpenShell MicroVMs that work on a copy of your project; `defenseclaw sandbox pull <name>` brings the changes back (see [sandboxes](/docs/features/sandboxes)). With sandboxes on, the app shows them in four places:

- The menu bar lists active sandboxes, blocked destinations with **Unblock**, and waiting asks with **Approve** and **Reject**.
- Notifications report a blocked destination you can unblock, an ask, a planted git repository, and hooks that cannot reach DefenseClaw. **Unblock for this sandbox** needs an unlocked Mac.
- The **Overview** card shows counts of active sandboxes, blocked sites, asks and alerts.
- The **Sandboxes** panel (`⌘⇧B`) lists sandboxes, their asks and the live activity feed, with stop, review, pull and undo actions.

The app never starts a harness session. It copies the `defenseclaw sandbox run` or `connect` command for you to paste into Terminal. It never installs OpenShell either; run `defenseclaw sandbox setup --install-openshell` in Terminal first.

Every button, notification and wizard field is listed in the [reference](/docs/reference/commands/tui#macos-app). The task steps are in [Watch from the TUI or app](/docs/how-to/sandboxes/watch-from-the-tui-or-app).
