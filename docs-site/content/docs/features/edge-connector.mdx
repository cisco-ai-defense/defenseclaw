The Edge Connector is a C engine for Linux edge devices such as Raspberry Pi, Jetson and industrial single-board computers. It checks an agent's tool calls on the device with local rules and content inspection. When local rules cannot decide, it asks a DefenseClaw Fleet gateway over MQTT. It works with no network at all for the local checks.

## When to use it

Use a [connector](/docs/connectors) for desktop coding agents such as Claude Code, Codex and Cursor. Those assume a reliable network, plenty of memory and a person at the keyboard. Use the Edge Connector when the agent runs on a small device, the network comes and goes, or a bad tool call causes a physical action.

## How a call is checked

The engine runs seven checks in order and stops at the first local block. A cache hit avoids a new Fleet request, but the earlier local checks still run.

The result is `ALLOW`, `BLOCK`, `WARN` or `PENDING`. The Fleet gateway decides unknown tool hashes by tool hash, and blocks them by default.

## What it does

- Detects secrets, PII, credentials, exfiltration, prompt injection and dangerous commands in tool arguments and LLM responses.
- Blocks requests to private ranges and cloud metadata addresses, and allows network destinations only from a public-IP allowlist.
- Tracks multi-step capability patterns, for example fetch from the network then run a shell command.
- Applies fixed rate limits: 60 tool calls, 30 network requests and 10 physical actuations per minute.
- Keeps an HMAC-chained audit ring so changes to retained history are detectable.
- Takes signed policy updates over MQTT with a rollback canary. Production builds accept HMAC updates only when built with `DCLAW_ALLOW_HMAC_OTA=ON` and given a separate HMAC key.

## Build profiles

| Profile | Features | Use |
| --- | --- | --- |
| `MINIMAL` | No MQTT, no content scan | Constrained builds with no Fleet |
| `STANDARD` | MQTT and content inspection | Raspberry Pi, Jetson, single-board computers |
| `EDGE` | MQTT, content inspection, bloom filter | Edge gateways |

Measure size, memory and latency on your own target; TLS libraries and compiler flags change them.
