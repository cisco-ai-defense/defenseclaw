The DefenseClaw terminal UI (TUI) is a full-screen, keyboard-driven dashboard over the `defenseclaw` CLI. It shows gateway status, alerts, scanned inventory, the audit trail, sandboxes, policies and setup in one place. Actions run the same CLI and gateway commands you would type, and show the command first.

## Open it

```bash
defenseclaw tui
```

Use a terminal of at least 80×24. Run `defenseclaw init` first so the panels have data.

This page is for a DefenseClaw you installed yourself. A managed computer (an
enterprise package, MDM or Setup) has no TUI and no `defenseclaw init`. On
Linux and macOS the user's `defenseclaw` offers only `sandbox` commands,
`help` and `--version`, and answers `tui`, `init` and anything else with
"This computer is managed; use `defenseclaw sandbox status` for your read-only status and `defenseclaw sandbox policy explain` for your policy. Other commands require an administrator."
and exit `2`. On Windows the managed `defenseclaw.exe` is the
administrator CLI. An administrator checks a managed computer as shown in
[On a managed device](/docs/reference/commands/tui#on-a-managed-device).

## Panels

Press the key shown on the tab strip from any panel. `Tab` and `Shift+Tab` cycle, and `Ctrl+P` jumps to a panel by name. Letter keys are capitals.

| Key | Panel | Shows |
| --- | --- | --- |
| `1` | Overview | Gateway status, connectors, active policy, health |
| `2` | Alerts | Recent guardrail and hook alerts |
| `3` `4` `5` `T` | Skills, MCPs, Plugins, Tools | Scanned inventory with block and allow actions |
| `6` | Inventory | Skills, plugins, MCPs, agents, tools, models, memory, IDE plugins |
| `7` | Sandboxes | OpenShell sandboxes, live activity, asks |
| `8` `9` `A` | Logs, Audit, Activity | Gateway logs, audit trail, output of commands you ran |
| `V` `N` `R` | AI Discovery, Runtime, Registries | What AI is installed, what ran, registries |
| `P` | Policies | Posture per connector, opt-in packs, rule packs |
| `0` | Setup | Setup tasks and the config editor |

## Five actions you will use most

1. **Check health.** On Overview, press `D` to run `defenseclaw doctor` in the background. The Doctor card shows the last result.
2. **Run a command.** Press `:` or `Ctrl+K` to search and run any command. The Risk column marks what changes things.
3. **Block or allow an asset.** On Skills, MCPs, Plugins or Tools, press `b` to block, `a` to allow, `u` to unblock. Each key shows the command before it runs.
4. **Change protection.** On Policies, press `m` to switch a scope between observe and action. `b`, `a`, `h` and `p` set block level, alert level, human approval and rule pack.
5. **Edit settings.** On Setup, press `c` for the config editor, then `S` to review and save.

`?` opens the help overlay for the panel you are on. `Ctrl+C` quits. `q` only closes a drawer.

With two or more connectors, `m` filters most panels by connector.
