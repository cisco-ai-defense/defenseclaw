These pages are runbooks written to an AI agent. Pick the task, copy its prompt into your agent, and the agent reads the runbook page and does the work. Every runbook tells the agent to look first, change nothing without your yes, and report back in a fixed format.

## Machine-readable docs

- `https://cisco-ai-defense.github.io/defenseclaw/llms.txt` lists every page with its Markdown URL.
- `https://cisco-ai-defense.github.io/defenseclaw/llms-full.txt` is the whole documentation in one file.
- Add `llms.md` to any page URL for that page as Markdown, for example `.../docs/get-started/install/llms.md`.

## Rules every runbook enforces

1. Observe first. The agent does not switch to action mode, change a fail mode, disable a connector, unblock a site or edit `config.yaml` by hand without your yes to that exact change.
2. The agent never prints a key or token.
3. On a managed computer the agent stops. A command that prints `This computer is managed` or `This device is managed` (exit `2` or `3`), or `"deployment_mode": "managed_enterprise"` in `defenseclaw status --json`, means your administrator owns DefenseClaw there.
4. The agent reports in a fixed format: what it ran, what it saw, what it changed, what is left for you.
