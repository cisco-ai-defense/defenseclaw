Fixes for installer messages and failed upgrades on macOS, Linux and Windows.

## `defenseclaw: command not found`

**Cause.** `~/.local/bin` is not on your `PATH` (macOS and Linux), or the terminal predates the install (Windows).

**Fix.** Run the line the installer printed, add it to your shell profile and open a new shell. On Windows open a new terminal. If the launcher is missing, run the install command again.

**Check.** `defenseclaw --version` prints a version.

## The installer stops before changing anything

**Cause.** The platform is unsupported: an Intel Mac, Windows on ARM64 or x86. Rosetta and x64 emulation do not change that.

**Fix.** Use a supported computer ([Install](/docs/get-started/install)).

**Check.** The installer's message names the unsupported architecture.

## Installer exit code 3

**Cause.** DefenseClaw is installed, but a connector refused to start, usually because the agent updated.

**Fix.** `defenseclaw doctor`, then the next step on the failing row.

**Check.** `defenseclaw doctor` shows the connector row as `[PASS]`.

## Installer exit code 4

**Cause.** DefenseClaw is installed, but the first-run quickstart failed.

**Fix.** Run the `defenseclaw quickstart ...` command the installer printed once the cause it named is fixed.

**Check.** The report says `status=ready`.

## `Another DefenseClaw install is running`

**Cause.** An install or upgrade holds the lock. A stale lock from a crashed run is cleared automatically.

**Fix.** Wait for it to finish, then run the command again.

**Check.** The command proceeds.

## `defenseclaw upgrade` changes nothing over SSH (Windows)

**Cause.** The installer continues in a new window, and an SSH session has no desktop.

**Fix.** Run the `powershell -File ... install.ps1` command the message prints, in the same terminal.

**Check.** The installer shows its result and sets the exit code.

## `Your configuration is from a newer DefenseClaw than X`

**Cause.** You installed an older release over data from a newer one.

**Fix.** `defenseclaw rollback`, or install the newer release again.

**Check.** `defenseclaw migrate --check` exits 0.

## `The running gateway did not stop`

**Cause.** The old gateway ignored the stop. Nothing was changed.

**Fix.** `defenseclaw-gateway stop`, then run the upgrade again.

**Check.** The upgrade completes.

## `missing release-provenance.json; refusing before services are stopped`

**Cause.** `defenseclaw upgrade` cannot upgrade 0.8.7 or older, or any 0.x on Windows.

**Fix.** Run the install command from [Install](/docs/get-started/install). See [Upgrade from 0.8.x](/docs/appendix/upgrade-from-0-8).

**Check.** `defenseclaw --version` shows the new version.

## An upgrade failed

**Cause.** A step failed. The installer put the previous version back and kept the attempt in `~/.defenseclaw/.failed-<time>`.

**Fix.** Read the newest log in `~/.defenseclaw/logs/`, fix what it names, run `defenseclaw upgrade` again. A cut-off run restores the install it was replacing first.

**Check.** `defenseclaw version` shows `OK All components in sync.`
