The creator builds a complete policy (admission preset, rule pack, suppressions, judges, webhooks) and exports it as YAML plus one install script. Quick Start asks six questions; Playground edits every section. Both share one draft.

<Callout type="info" title="Nothing is uploaded">
Evaluation runs in your browser with compiled copies of the bundled Rego (admission and guardrail). Your draft and test inputs never leave the page; saved progress lives in `localStorage`.
</Callout>

## Use the creator

1. Pick a posture (Permissive, Balanced or Strict), choose what to block, how aggressive to be, and where alerts go.
2. On Review, run the canned scenarios in Live Test. They use the selected policy mode; observe mode reports `alert` for the bundled CRITICAL guardrail cases.
3. Open in Playground to fine-tune, then download the install script. A share link holds the whole policy in its URL fragment; treat it like the YAML.

## What the creator cannot do

- Live Test evaluates only the admission and guardrail Rego. It does not run ActionFacts parsing, CEL, regex, YARA or bounded chains.
- Firewall and audit choices are planning notes. They are left out of the export and `policy activate` does not apply them.
- The HITL choice stays in the policy file. Turn it on with `defenseclaw guardrail hilt on --min-severity MEDIUM`.
- Playground's keep host mode choice omits `guardrail.mode`, so activation keeps the host's mode.
- Browser regex checks use V8; the gateway uses Go RE2. Final validation happens on the host.
- Admission first-party entries need an exact asset name and at least one `source_path_contains` path pin ([admission](/docs/reference/scanning/admission)).

## Install the policy

The script writes the policy files and runs `defenseclaw policy activate`. That copies admission and levels into `config.yaml`. The rule pack is not enforced until you validate and switch to it:

```bash
defenseclaw policy activate my-policy
defenseclaw guardrail validate-pack ~/.defenseclaw/policies/guardrail/my-policy
defenseclaw guardrail use-pack my-policy
```

## Check it worked

Test the script in a throwaway home before you run it on a shared install. Read the script first; it inlines every pack file.

1. Isolate the home and list the script's write targets.

   ```bash
   INSTALL_SCRIPT="$HOME/Downloads/install-my-policy.sh"
   REAL_HOME="$HOME"
   REAL_DEFENSECLAW_HOME="${DEFENSECLAW_HOME:-$HOME/.defenseclaw}"
   VERIFY_HOME="$(mktemp -d "${TMPDIR:-/tmp}/defenseclaw-policy-verify.XXXXXX")"
   export HOME="$VERIFY_HOME" DEFENSECLAW_HOME="$VERIFY_HOME/.defenseclaw"
   grep -nE '^(cat >|defenseclaw )' "$INSTALL_SCRIPT"
   ```

2. Create a minimal install, run the script and read the policy back. Use the name the creator showed in place of `my-policy`.

   ```bash
   defenseclaw init --non-interactive --yes --connector codex \
     --skip-install --no-start-gateway --no-verify
   bash -n "$INSTALL_SCRIPT" && bash "$INSTALL_SCRIPT"
   defenseclaw policy show my-policy
   ```

3. Compile and test the Rego, read the effective values, and dry-run an admission decision. `opa` is used when it is on `PATH`, otherwise the engine inside `defenseclaw-gateway`.

   ```bash
   defenseclaw policy validate --rego-dir "$DEFENSECLAW_HOME/policies/rego"
   defenseclaw policy test --rego-dir "$DEFENSECLAW_HOME/policies/rego" --verbose
   defenseclaw config get guardrail.block_at --effective
   defenseclaw-gateway policy evaluate --target-type skill \
     --target-name test-skill --severity HIGH --findings 3
   ```

   The JSON decision should match the HIGH action you set in the creator.

4. Validate and switch to the rule pack, then clean up. The throwaway gateway is not running, so `use-pack` warns that the audit event was not recorded. That is expected.

   ```bash
   defenseclaw guardrail validate-pack "$DEFENSECLAW_HOME/policies/guardrail/my-policy"
   defenseclaw guardrail use-pack my-policy
   rm -rf -- "${VERIFY_HOME:?}"
   ```

To promote, run the reviewed script and `use-pack` again with `HOME="$REAL_HOME" DEFENSECLAW_HOME="$REAL_DEFENSECLAW_HOME"`.
