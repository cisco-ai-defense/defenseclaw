Take a 30-second inventory of the AI on a machine.

## Before you start

`agent discover` and `aibom scan` need no gateway. `agent usage`, `agent ide-plugins` and the TUI panel read the gateway's continuous scan, so start the gateway and turn it on first.

## Steps

1. List the agents that are installed.

   ```bash
   defenseclaw agent discover
   ```

   ```text
                        Agent discovery (cached)
   ┃ Connector   ┃ Installed ┃ Configured ┃ Active / Mode ┃ Config ┃ Binary                ┃
   │ codex       │ yes       │ no         │ no            │ -      │ /usr/local/bin/codex  │
   │ claudecode  │ yes       │ no         │ no            │ -      │ /usr/local/bin/claude │
   │ openclaw    │ no        │ no         │ no            │ -      │ -                     │
   …
   ```

   Add `--json` for machine output. It carries full local paths, so treat it as host inventory. `--no-emit-otel` keeps the run strictly local.

2. Turn on continuous discovery and scan now.

   ```bash
   defenseclaw agent discovery enable --restart --scan
   defenseclaw agent discovery status
   ```

   A fresh install has discovery off. `enable` also turns on runtime planes A and B. It asks `Proceed? [Y/n]` first; add `--yes` in scripts.

3. Read the inventory.

   ```bash
   defenseclaw agent usage
   defenseclaw agent usage --category local_model --detail
   defenseclaw agent ide-plugins --user alice --ai-only
   ```

   The `ide-plugins` table looks like this (sample data; your plugins differ):


4. Open the TUI panel. Run `defenseclaw tui` and press `V`. Local models get their own table above agents and tools. Press `a` to show all models, `t` to switch tables.

5. Export an AI bill of materials.

   ```bash
   defenseclaw aibom scan --json > aibom.json
   defenseclaw aibom scan --summary
   ```

   `--only skills,mcp` limits categories. `--connector <name>` limits to one connector. Each item carries a `provenance` block (schema version, content hash, configuration generation, DefenseClaw version). The BOM is not signed and has no CycloneDX format.

## Check it worked

`agent discovery status` shows `Configured: enabled` and a last-scan time. `aibom scan` prints a count per category. A `-` means that category is not collected for the connector.

## Turn it off

```bash
defenseclaw agent discovery disable
```

It asks `Proceed? [Y/n]`; `--yes` skips the question. `defenseclaw agent discovery disable` turns off AI discovery and the runtime planes that `enable` turned on. The selected planes are kept for the next `enable`.
