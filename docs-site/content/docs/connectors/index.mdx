A connector is how DefenseClaw guards one coding agent. **Hook** connectors register with the agent's own hooks or plugin, and the agent keeps talking to its model provider directly. **Proxy** connectors send the agent's model traffic through the DefenseClaw guardrail proxy.

## Pick your agent

| Agent | Type | Can block | Can ask you first | OS |
| --- | --- | --- | --- | --- |
| [Claude Code](/docs/connectors/claudecode) | Hook | Prompts and tool calls | `PreToolUse` | Linux, macOS, Windows |
| [Codex](/docs/connectors/codex) | Hook | Prompts and tool calls | No | Linux, macOS, Windows |
| [GitHub Copilot CLI](/docs/connectors/copilot) | Hook | Tool calls | `preToolUse` | Linux, macOS, Windows |
| [Cursor](/docs/connectors/cursor) | Hook | Prompts and tool calls | No | Linux, macOS, Windows |
| [Devin](/docs/connectors/devin) | Hook | Prompts and tool calls | No | Linux, macOS, Windows |
| [Antigravity](/docs/connectors/antigravity) | Hook | `PreToolUse` | `PreToolUse` | Linux, macOS, Windows |
| [Kiro](/docs/connectors/kiro) | Hook | Tool calls; prompts in Kiro IDE | No | Linux, macOS, Windows |
| [OpenCode](/docs/connectors/opencode) | Plugin | Tool calls | No | Linux, macOS, Windows |
| [Amp](/docs/connectors/amp) | Plugin | Tool calls and results | `tool.call`, `tool.result` | Linux, macOS, Windows |
| [Hermes](/docs/connectors/hermes) | Hook | `pre_tool_call` | No | Linux, macOS, Windows |
| [OpenClaw](/docs/connectors/openclaw) | Proxy | Requests, responses, tool calls | `before_tool_call` | Linux, macOS |
| [ZeptoClaw](/docs/connectors/zeptoclaw) | Proxy | Requests, responses, tool calls | No | Linux, macOS |

Where an agent cannot ask, a confirm verdict becomes an alert with the original action kept. You can review it in audit or the TUI, but you cannot resume the call. The [capability matrix](/docs/reference/apis/capability-matrix) has the full per-connector detail, and [Human approval](/docs/features/guardrail) has the per-event matrix.

One gateway can serve several hook connectors, each with its own posture under `guardrail.connectors.<name>`. Choose **Add**, not Replace, when you run a second `setup <connector>`. Proxy connectors own the traffic plane and cannot be combined this way. See [Multi-connector](/docs/how-to/agents/add-or-remove-an-agent).

## OpenShell sandbox

`defenseclaw sandbox run <harness>` runs a coding agent in an NVIDIA OpenShell sandbox. The [sandbox guide](/docs/how-to/sandboxes/run-an-agent) has setup and every command.

- **Run today:** [Claude Code](/docs/reference/connectors/claudecode#openshell-sandbox), [Codex](/docs/reference/connectors/codex#openshell-sandbox), [OpenCode](/docs/reference/connectors/opencode#openshell-sandbox), [GitHub Copilot CLI](/docs/reference/connectors/copilot#openshell-sandbox), [Kiro](/docs/reference/connectors/kiro#openshell-sandbox), [Hermes](/docs/reference/connectors/hermes#openshell-sandbox) and [Antigravity](/docs/reference/connectors/antigravity#openshell-sandbox).
- **Cannot run yet:** [Amp](/docs/reference/connectors/amp#openshell-sandbox), [Cursor](/docs/reference/connectors/cursor#openshell-sandbox) and [Devin](/docs/reference/connectors/devin#openshell-sandbox) need a vendor account before any agent turn, so their images have not passed the hook check.

OpenClaw and ZeptoClaw do not run in a sandbox.
