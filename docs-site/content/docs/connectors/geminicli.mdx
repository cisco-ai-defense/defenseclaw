<Callout type="warning" title="Deprecated on every platform">
DefenseClaw no longer offers new Gemini CLI setup on Windows, macOS, or Linux.
Use the supported [Antigravity connector](/docs/connectors/antigravity) instead.
</Callout>

Gemini CLI has been removed from installers, setup pickers, the TUI, active
connector matrices, and live-test lanes. An explicit `defenseclaw setup
geminicli` command now refuses before changing configuration.

Gemini CLI is also excluded from AI-asset discovery and from skill, plugin,
MCP, and CodeGuard catalog or install operations. MCP set/unset is disabled;
use Antigravity's supported asset surfaces for new work. The legacy Gemini CLI
home and `settings.json` paths remain resolvable only for doctor, verified
receipt migration, teardown, and uninstall cleanup.

## Remove an existing managed installation

DefenseClaw retains the old Gemini CLI lifecycle code only so existing users
can restore their pre-DefenseClaw settings without losing unrelated Gemini
configuration:

```bash
defenseclaw setup remove geminicli --yes
```

Full DefenseClaw uninstall also invokes the same receipt-bound cleanup. The
cleanup removes only DefenseClaw-owned hook and telemetry entries, restores an
authenticated pristine backup when it is still safe to do so, and preserves
foreign or drifted content for manual review.

For new configuration, run:

```bash
defenseclaw setup antigravity
```
