DefenseClaw for macOS is a native SwiftUI companion app for Macs with Apple
silicon, running macOS 14 or newer. It adds a menu-bar status view, native
dashboards and setup flows. It connects only to the local DefenseClaw
installation: the gateway REST API on `127.0.0.1`, and the audit database,
logs and configuration under `~/.defenseclaw`. Actions that change something
run through the `defenseclaw` CLI, and their output appears in the
**Activity** panel. Sandbox unblocks and ask decisions go straight to the
DefenseClaw daemon's API instead.

## Download and install

1. Download `DefenseClawMac-<version>-macos-arm64.dmg` from the
   [latest release](https://github.com/cisco-ai-defense/defenseclaw/releases/latest).
2. Open the disk image and drag **DefenseClawMac** to **Applications**.
3. Open the app. If the DefenseClaw CLI and gateway are not installed, the
   first-run sheet offers to install them. It downloads that release's
   `install.sh`, verifies it against the release's `checksums.txt`, and runs
   it. The CLI and gateway go into `~/.defenseclaw` and `~/.local/bin`.

The app itself holds no DefenseClaw runtime. To update, use the app's
**Update** button, or run `install.sh` again: it also updates the app in
`/Applications` or `~/Applications`. See [Upgrade](/docs/get-started/upgrade).

## Panels

The main window's sidebar groups the panels:

| Group | Panels |
| --- | --- |
| Monitor | Overview, Alerts, Logs, Audit, Activity |
| Govern | Skills, MCPs, Plugins, Tools, [Sandboxes](/docs/setup/sandbox/apps#sandboxes-panel-in-the-macos-app) |
| Discover | Inventory, AI Discovery, Runtime, Registries |
| Configure | Setup: the setup wizards (including the [Sandbox wizard](/docs/setup/sandbox/apps#macos-sandbox-wizard)) and the config editor |

They mirror the [TUI](/docs/tui) panels. **Settings** has General,
Monitoring, Notifications and Connection tabs.

## OpenShell sandboxes

When sandboxes are on, the app shows them in the menu bar, desktop
notifications, an Overview card and the Sandboxes panel. It copies the
`defenseclaw sandbox run` or `connect` command for you to paste into
Terminal. See
[Sandboxes in the TUI and macOS app](/docs/setup/sandbox/apps#macos-app).
