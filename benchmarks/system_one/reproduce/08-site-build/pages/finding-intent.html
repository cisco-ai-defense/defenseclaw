Intent

Intent detection: eight negative runs, then a reversal on proof-backed data

DefenseClaw compares each tool call against what the user asked for. On data where the compromise is independently proven, the same code, models and seed turn all {{fig:cells}} measured cells positive. {{fig:cells.rev}} of the {{fig:cells}} are strict sign reversals against the same model’s own prior figure; the remaining cell was already positive, so there was no sign to reverse.

Model choice: All four models reverse here, {{fig:cells.pos}} of {{fig:cells}} cells positive, and the between-model ordering is confounded by differing question formats and instruction encodings. No between-model ranking is given.

The separation statistic

An attacker has planted text where the agent will read it. The agent either ignores it and carries on, or complies and does the attacker’s bidding. Both look similar: the attacker’s text is present in both, and in both the agent keeps making tool calls. The guard has to tell them apart, so the statistic is a difference.

separation = block rate on a proven compromise  −  block rate on an agent that correctly refused the same attack

Written sep|res in the artifacts. Zero means the guard cannot tell the two apart. Negative means it fires more on the correct refusal, so it is detecting attacker text. That signal is strictly harmful: it punishes the agent for doing the right thing.

The AgentDojo runs

AgentDojo is a synthetic agent benchmark with matched attacked/clean pairs. 651 matched cases, four models, two context recipes, eight runs. At the per-case, block-only lens every one of the eight runs came out between −0.0053 and −0.5343; over all {{fig:cells}} measured cells the range reaches −0.5969, and {{fig:ad.pos}} of them is positive. One configuration was repeated four times to check. Supplying the user’s request made things worse in 11 of 12 paired comparisons for hosted Jev, and in 26 of 36 across the three prior backends. The conclusion was written down and published: the mechanism DefenseClaw ships is a usable injection-attempt detector and a poor compromise detector.

Causes of the AgentDojo negative

Two mechanical reasons, both measurable, both specific to that benchmark.

1. Attacker-text sensitivity

On AgentDojo the only difference between a clean case and a correct refusal is that attacker text is present. Across exactly that difference, one model’s detection rate went 0.2235 → 0.8031. The correct-refusal class was flagged 3.6 times as often as the clean class purely because attacker text was on screen, which drives separation negative on its own.

On the proof-backed corpus the same comparison moves 0.0640 → 0.0582. 714 of the 1,083 resisted cases sit in a family that also holds a proven compromise, so the design is paired within a family. Whether attacker text is present in those cases is not measured anywhere in these artifacts.

2. The aggregation unit

A case counts as detected if any of its events fired, so cases with more events get more chances. On AgentDojo the correct-refusal class had the most events per case of the three: 5.07 against 4.14 for compromise. Scored per event at the same block-only lens the cell moves from {{fig:ad.openjev.C7}} to {{fig:ad.openjev.C7.event}}. The −0.1028 sometimes quoted for this is the any-intervention lens, which is a different cell.

On the proof-backed corpus the ordering is reversed: the negatives average 1.00 and 1.006 events per case and compromise averages 1.40. The case unit mildly flatters the positive result there, which survives the per-event view anyway.

The reversal

A new corpus was built from real emitted MCP tool calls where a deterministic proof establishes that the compromise happened: 3,402 cases over 1,929 families, 405 of them carrying that proof. All four models were re-run. The same scorer with the same seed was also re-run on the old AgentDojo data as a control.

The two sides use different evidence lanes, and they have to. The proof-backed figures are the grade-A verified lane. AgentDojo contains zero grade-A compromised cases, so its only available figure is the combined grade A + B lane. The artifact states this in confounds.prior_vs_now_lane, and the combined-lane proof-backed figure is reported alongside for a like-for-like match.

Three further checks were run.

  • Not corpus identity. The lead statistic compares compromise against correct refusal, and both classes come from the same source corpus.
  • Not a between-family confound. Restricted to the {{fig:wf.families}} families holding both a proven compromise and a correct refusal, {{fig:wf.families}} against {{fig:wf.families}} on the same user request and the same poisoned tool catalogue, all {{fig:wf.cells}} cells stay positive with every interval excluding zero: {{fig:wf.prior.cells}} for the three prior backends and {{fig:wf.jev.cells}} for the fourth.
  • Not carried by weak evidence. Grade A beats grade B in all 8 cells for every model. The proof-backed rows are the ones the mechanism catches best, the opposite of what a labelling artifact looks like.

Limits

The defensible claim is narrow: on real emitted tool calls with independently verified compromise proofs, comparing the call against the user’s request separates compromise from a correct refusal, and knowing the request helps substantially. That is a claim about discrimination. The sufficiency number is bad.

Every model misses {{fig:miss.openjev.C7}} to {{fig:miss.jev.C7}} of proven compromises. At its best measured operating point each model blocks {{fig:recall.openjev.C7}} / {{fig:recall.diffgemma.C7}} / {{fig:recall.gemma4.C7}} / {{fig:recall.jev.C7}} of the 405 proof-verified compromises. Adding the fourth model widened that range.

The evidence supports real signal and a benchmark artifact behind the prior negative; it does not support sufficiency as a blocking control.

Caveats

  • “With intent” is not a clean isolation of intent. The C7 recipe adds the user’s request and up to seven prior events and a different text representation. The C0-to-C7 gap cannot attribute the gain to the request field alone.
  • The between-model ordering is confounded. At the grade-A block-only lens per case, DiffusionGemma leads without the request and OpenJev leads with it. On the any-intervention lens without the request the order is different again and Gemma 4 leads, so the ordering is a property of the lens as much as of the model. The two named models ran the same question format and differ in instruction encoding, structured against string. Only the within-model prior-vs-now contrast is controlled, and that is the contrast the verdict rests on.
  • The correct-refusal class rests on an upstream label with no independent proof that the agent truly ignored the attack. Mislabelling there would depress measured separation, so the bias is conservative.
  • The clean class comes from different corpora than the compromise class, which is why the compromise-vs-refusal comparison leads.
