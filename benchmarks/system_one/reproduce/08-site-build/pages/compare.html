The disagreement queue

Every one of the {{fig:exp.rows}} cases where the four deciders did not agree, joined to the blinded adjudicator's verdict. Filter by vote pattern, truth grade, surface and verdict.

Metadata only, by design. {{fig:exp.fields}} fields per case: truth grade, surface, event count, source dataset, the four votes and the verdict. The tool call, the user request, and the adjudicator's two free-form fields (reason and apparent_task) are not here. Every row in both files is download-only, and those two fields are withheld written rationale.

The corpus case_id is withheld as well: it identifies a row in a download-only corpus. The first column is a position in this table, stable for a given build. The {{fig:exp.datasets}} source datasets named here are all public and linked on data.

This table is the one place on the site that publishes per-case structure, and the redistribution rule carries an explicit carve-out for it. Each row is {{fig:exp.ints}} small integers into the code tables printed above, and the {{fig:exp.rows}} rows collapse to {{fig:exp.distinct}} distinct tuples, so the published payload distinguishes {{fig:exp.distinct}} readings and carries no identifier and no corpus text. The rule and its carve-out are stated together.
