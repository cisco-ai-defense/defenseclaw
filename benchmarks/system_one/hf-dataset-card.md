# DefenseClaw System One Evaluation Evidence v1

Private evaluation evidence for deterministic guardrails, Jev, OpenJev, Von,
and contextual LLM cascades. This repository is evaluation-only and is not
approved for training, synthetic generation, teacher context, distillation, or
public redistribution.

The repository records immutable protocol files, source references, stage
selection manifests, value-free predictions, metrics, latency, token usage,
cost, Pareto comparisons, culling decisions, environments, and checksums for
the governed 1,000 to 10,000 to 100,000 evaluation funnel.

Source payloads are included only when their source manifest permits private
redistribution. Restricted and download-only sources are represented by stable
case IDs, immutable revisions, digests, and rehydration instructions. Result
artifacts omit input state, prompts, raw provider responses, rationales,
credentials, authorization headers, and evidence values.

Truth lenses remain separate: exact or outcome-backed, complete-trajectory
contextual, benign-only operational, protected three-way, and diagnostic or
unknown. Aggregate metrics must always be interpreted with their bound truth
lens, stage selection, model revision, code commit, and checksum manifest.
