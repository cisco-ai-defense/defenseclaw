# Original developer specification

> **Status: archived product-planning record.** This file no longer defines
> installation, scope, supported connectors, runtime topology, or roadmap.

The original specification described the first DefenseClaw CLI/TUI concept:
pre-use scanning, block/allow policy, and an operator alert surface layered over
OpenClaw and OpenShell. The implemented product has since expanded and changed
its connector, configuration, observability, packaging, and release contracts.

Use current authorities instead:

- [What is DefenseClaw?](https://cisco-ai-defense.github.io/defenseclaw/docs/get-started/what-is-defenseclaw/)
  for the product model;
- [Connector compatibility](https://cisco-ai-defense.github.io/defenseclaw/docs/connectors/compatibility/)
  for supported runtime surfaces;
- [`../ARCHITECTURE.md`](../ARCHITECTURE.md) for repository ownership;
- [`../../schemas/README.md`](../../schemas/README.md) for schema ownership;
- [`../RELEASE_RUNBOOK.md`](../RELEASE_RUNBOOK.md) for release engineering.

The obsolete installation examples and roadmap assertions were removed so this
historical record cannot be mistaken for active guidance.
